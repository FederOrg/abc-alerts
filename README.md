# ABC Alerts

Sistema automático de notificaciones de ofertas docentes del portal ABC.

El objetivo es consultar diariamente las ofertas publicadas en el sistema de Actos Públicos Digitales (APD) de la Dirección General de Cultura y Educación, filtrar aquellas compatibles con las incumbencias docentes configuradas y enviar un resumen por correo electrónico.

---

## Características

- Consulta automática de ofertas docentes.
- Soporte para múltiples distritos.
- Filtrado por modalidad/nivel.
- Filtrado por código de incumbencia.
- Evita enviar ofertas repetidas.
- Genera correos HTML con tabla de resultados.
- Ejecución programada mediante GitHub Actions.
